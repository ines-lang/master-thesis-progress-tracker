S0 is not simulated: it is the timing of the public records. S1 uses only the satellites whose fire data were openly available in near real time, the ones behind the public record, so S1 against S0 is a clean validation. S2 is the main sweep. The extended public layer (S3) is simulated without validation, with a conservative detectability filter written before running, so any gain it shows is a lower bound; S3 then checks only the S2 optimum and nearby setups, not a full new sweep. S4 is the former S3, the commercial layer. One fixed ground-station set is used in all scenarios.
