The design freeze comes first, so S1 and S2 run on a design that no longer changes. The detection gain per satellite combines when each satellite passes with whether its sensor could detect the fire. Sentinel-3 SL_2_FRP, GOES and the official perimeters are now in S0 for all seven events; the new events still need registry entries before the per-event pipeline can run.FY-3D moved to S3 because its fire product is not openly available in near real time.
